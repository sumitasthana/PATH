## Adding a new update

Create `WEEKLY_UPDATES_<DDMMMYYYY>.md` in this folder, for example
`WEEKLY_UPDATES_03NOV2026.md`. Start it with a title line and a link back to this index,
then add a row to the table above, newest first. Each page repeats the short glossary so
it can be read on its own.
